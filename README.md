# AV資料管理系統

一個整合了自動爬取和網頁瀏覽的AV影片資料管理工具。

## 📋 功能特色

### 🔍 自動掃描爬取
- 掃描指定目錄中的影片檔案
- 自動從檔名提取AV番號
- 從JavCup網站爬取詳細資訊
- 自動下載並儲存封面圖片
- 支援多種影片格式：MP4, AVI, MKV, DIVX

### 🌐 網頁瀏覽介面
- Netflix風格的深色主題設計
- 封面牆展示所有影片
- 即時搜尋功能
- 多維度篩選（女優、系列、類型）
- 響應式設計，支援手機和桌面
- 即時進度顯示和日誌

### 📊 即時監控
- WebSocket即時通訊
- 爬取進度即時更新
- 錯誤日誌即時顯示
- 可隨時停止掃描過程

## 🚀 快速開始

### 1. 環境要求
- Python 3.7 或更高版本
- 網路連接（用於爬取資料）

### 2. 安裝與啟動
```bash
# 進入項目目錄
cd av

# 使用啟動腳本（推薦）
python start.py

# 或手動安裝依賴
pip install -r requirements.txt
python app.py
```

### 3. 使用方法
1. 訪問 http://localhost:5000
2. 在頁面頂部輸入要掃描的目錄路徑
3. 點擊「開始掃描」按鈕
4. 等待掃描完成，期間可以觀看即時進度
5. 使用搜尋和篩選功能瀏覽資料

## ⚙️ 配置選項

### 爬蟲設定
- 預設掃描目錄: `/Volumes/BTAV/TEST`
- 請求間隔: 1.2秒（避免被封鎖）
- 超時設定: 10秒
- 支援的影片格式: `.mp4`, `.avi`, `.mkv`, `.DIVX`

### 網頁設定
- 服務器端口: 5000
- 最大日誌條數: 50條
- 篩選標籤顯示上限: 10個

## 🛠️ 自定義修改

### 修改爬取來源
如需更換爬取來源，修改 `app.py` 中的 `AVScraper` 類：
```python
def __init__(self, base_url="https://your-source.com"):
    self.base_url = base_url
```

### 修改檔名解析規則
修改 `extract_av_code` 方法中的正則表達式：
```python
pattern = r'([A-Za-z]+-\d+)'  # 當前格式：ABC-123
```

### 修改UI樣式
編輯 `templates/index.html` 中的CSS樣式部分。

## ⚠️ 注意事項

1. **網路要求**: 需要穩定的網路連接來爬取資料
2. **目錄權限**: 確保程式有讀取掃描目錄的權限
3. **磁碟空間**: 封面圖片會佔用一定的磁碟空間
4. **爬取頻率**: 內建延遲機制，請勿手動減少延遲時間
5. **法律合規**: 請確保使用時遵守當地法律法規

## 🐛 常見問題

### Q: 掃描停留在某個檔案不動
A: 可能是網路問題或目標網站暫時無法訪問，可以點擊停止後重新開始

### Q: 無法找到某些番號的資訊
A: 可能是番號格式不標準或目標網站沒有該資料，系統會自動跳過

### Q: 封面圖片無法顯示
A: 檢查 `data/covers/` 目錄是否存在且有寫入權限

### Q: 網頁無法連接
A: 確保防火牆沒有阻擋5000端口，或檢查是否有其他程式佔用該端口
